# Quiz Ôn Tập GMHS - Khoa Gây Mê Hồi Sức

Ứng dụng web ôn tập trắc nghiệm chuyên ngành Gây mê Hồi sức (GMHS) với ngân hàng **451 câu hỏi chuẩn** kèm đáp án chi tiết.

## 🚀 Trải nghiệm trực tiếp
👉 **Link làm bài trắc nghiệm:** [https://hsl2006.github.io/quizz-GMHS/](https://hsl2006.github.io/quizz-GMHS/)

---

## 📚 Cấu trúc bộ câu hỏi (451 câu)
- **Phần I: Chọn 1 đáp án (199 câu)**: Câu hỏi trắc nghiệm kiến thức tổng quát, chăm sóc người bệnh, kiểm soát nhiễm khuẩn, hồi tỉnh...
- **Phần II: Chọn nhiều đáp án (131 câu)**: Dạng câu hỏi chọn nhiều phương án đúng kèm xác nhận kết quả.
- **Phần III: Đúng - Sai (121 câu)**: Các nhận định chuyên môn thực hành lâm sàng.

## ✨ Tính năng nổi bật
- 🎯 **Nhiều chế độ làm bài:**
  - *Chế độ Ôn tập:* Hiển thị ngay đáp án đúng/sai (xanh lá/đỏ) khi chọn.
  - *Chế độ Thi thử:* Ẩn kết quả, chấm điểm tổng kết và xem lại chi tiết sau khi bấm Nộp bài.
- 📋 **Bảng số câu hỏi (Grid 1 -> 451):** Nhảy nhanh đến bất kỳ câu hỏi nào trong 1 cú click.
- 🎲 **Thi thử ngẫu nhiên:** Hỗ trợ bốc ngẫu nhiên 50 hoặc 100 câu thi thử.
- 🌓 **Giao diện hiện đại:** Hỗ trợ chế độ Sáng / Tối (Dark mode), tối ưu hiển thị mượt mà trên cả Điện thoại và Máy tính.
- ⌨️ **Phím tắt bàn phím:** Dùng phím `←` `→` để chuyển câu, phím `1`, `2`, `3`, `4` (hoặc `A`, `B`, `C`, `D`) để chọn nhanh.

## 📂 Danh mục file trong dự án
- `index.html`: Giao diện web chạy trực tiếp trên GitHub Pages.
- `questions.json`: Toàn bộ 451 câu hỏi chuẩn hóa dạng JSON.
- `convert_quiz.py`: Mã nguồn Python dùng để trích xuất và xử lý câu hỏi từ file Word gốc.
- `BỘ TEST KHOA GMHS CHUẨN_1.docx`: Tài liệu đề thi gốc.
